= mathesis
:toc:

The estate's maths section. It answers "where does that proof live?" for
every hyperpolymath repository: which repos carry proofs, in which prover,
whether the work reads as theory or engineering, which have holes or
axioms, and where each repo's proof-status file is.

Proofs stay in their home repositories. mathesis points at them. Later it
will also hold the Agda sources for theory that has no other natural home.

The rules for where a proof *should* live are not here: they are
`standards/3-practice/PROOF-POLICY.adoc` (Creusot for Rust, SPARK for Ada,
Idris2 for APIs, ABIs and engineering properties, Agda for theory rechecked
in Rocq and Lean). The working method is the proof-craft skill.

== What is here

[cols="1,3"]
|===
|`catalogue/catalogue.adoc` |The catalogue: one row per repository with proof files of its own, split into theory and engineering. Generated; do not edit by hand.
|`data/` |The census it is built from. Each `*.jsonl` file has one sorted-key JSON object per line.
|`data/summary.md` |The census summary, including the per-repo table with declaration counts.
|`scripts/census/` |`run-census.sh` (whole census), `census-repo.sh` (one repo), `summarise.sh`, `generate-catalogue.sh`, and proof-craft's `proof-holes.sh`.
|`Justfile` |`just census`, `just catalogue`, `just catalogue-check` (the committed catalogue matches the committed data).
|===

== How the census works

. *List repositories.* `data/repos.jsonl` is the input. Agent sessions build
  it with the Claude Code remote `list_repos` tool, because the GitHub API is
  not reachable from them.
. *List proof files cheaply.* Each repository is cloned blobless with
  `--no-checkout`, and its file names are filtered by prover extension:
  Agda, Idris2, Lean, Rocq, Isabelle, TLA+, Dedukti/Lambdapi, SMT-LIB, TPTP,
  SPARK, Why3, F*, Dafny and Alloy.
. *Read only the proof files.* Only those files are checked out. Top-level
  declaration names go to `decls.jsonl`, and proof-craft's `proof-holes.sh`
  inventories holes, axioms, disabled checkers and policy breaches
  (`holes.jsonl`).
. *Set the template aside.* Files the RSR template ships
  (`data/template-paths.txt`) are boilerplate wherever they appear. The
  catalogue counts only a repo's *own* files.

== Reading the catalogue (first pass, 2026-10-26)

The first census covered 476 repositories:

* *Scope:* 462 repositories were cloned; 5 forks and 9 awesome-lists were
  skipped. 275 have proof files, and 239 still have them once template
  boilerplate is set aside.
* *Unreached:* 37 private repositories could not be cloned and are listed at
  the end of the catalogue, among them `cut-calculus`.
* *Possibly missing:* the listing returned only repositories pushed since
  2026-09-15, so older, untouched repos may be absent. Add them to
  `data/repos.jsonl` and rerun.
* *Theory or engineering* is a heuristic: more Agda, Lean, Rocq or Isabelle
  files than Idris2 or SPARK files reads as theory. Confirm each row against
  PROOF-POLICY.
* *Hole, axiom, unsafe and policy counts* are textual candidates, not kernel
  verdicts. The kernel is the authority. `import Mathlib` shows under
  policy.
* *Declaration counts* in `data/summary.md` overcount Agda and Idris2:
  every column-0 type signature counts, helpers included.
* *Older template copies* survive as "own" files in some repos: for example
  asdf-tool-plugins, whose plugins each carry a stubbed `Layout.idr`.
* *Fixtures:* files under `tests/`, `fixtures/`, `corpus/` or `benches/` are
  counted as fixtures. `examples/` is not, because some verifiers (Atoma)
  keep real verification conditions there.
