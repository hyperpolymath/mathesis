=== The honest nuance you must not lose

* "THY-1 is proven" is about a graph model. That the model matches Cargo's
  feature resolution is argued, not proved.
* The proof result is a CI run that this session read, not a local run: this
  container had no Guix and no provers.
* The six `must` probes passed when run by hand. No runner executes `must`
  probes yet, so the contract is not a gate on its own. `just check` in CI
  enforces three of the six rules: `views-current` (the catalogue and atlas
  checks), the public frame of `no-private-name` (`census-atlas.mjs check`),
  and `rows-have-provenance` (the atlas row validation). It does not enforce
  `receipts-stay-home`, `home-theorem-has-receipt` (a missing receipt yields
  `ungraded`, not a failure) or `no-hand-typed-grade`.
* Census counts are textual candidates, not kernel verdicts.

=== Known-incomplete but honestly fenced

* Theorems without an accepted receipt: fenced by the registry, which shows
  each as `ungraded` with the reader's reason, never as a grade.
* Private repositories: fenced by `census-atlas.mjs check` and both census
  writers, which refuse an entry outside the public frame.
* A stale view or a failing proof: fenced by `just check` in CI, whose
  controls (`tests/golden/check_controls_test.sh`) show that each fails it.
