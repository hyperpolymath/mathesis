= The echidna proof route: theorems, receipts and grades (2026-11-09)
:toc:

This is a dated, source-anchored record of the proofs the echidna proof route
rests on. It is *not* a claims registry: the atlas README leaves that design
open. Each theorem lives in its home repository, which owns its statement,
receipts and status (PROOF-POLICY §2.2, §8.5). This page points at them. The
Proof Witness Grades (PWG) below are derived from those receipts, not
assigned here.

An agent drafted this record and the statement comparison it cites. Neither
has been reviewed by the owner yet, so neither counts as independent
corroboration.

NOTE: 2026-11-10 (re-anchoring plan WO 2.4): the grades below are an agent's
reading of the receipts on 2026-11-09. No machine derived them. The canon
reader of PROOF-POLICY §8.5.1 is now the only source of a grade in Mathesis,
and the claims registry
(link:../../atlas/generated/registry.adoc[`docs/atlas/generated/registry.adoc`])
pins no echidna claim yet. Read these grades as history, not as a current
record.

The plan these rows come from is
https://github.com/metadatastician/standards/blob/main/docs/ULTRAPLAN-ECHIDNA-PROOF-ROUTE-2026-11-04.adoc[the echidna proof-route ultraplan]
(ladder rows in brackets; v0.2.4 is metadatastician/standards#1434).

== Census corrections made with this record

* The catalogue rows for echidnabot and hypatia were refreshed from a census
  of those two repositories on 2026-11-09. echidnabot now shows its Agda,
  Lean and Rocq theory files.
* `scripts/census/build-rows.sh` chose whichever status document sorted
  first, so hypatia was listed under `docs/proof-debt.adoc`. It now prefers
  a `PROOF-STATUS` file, then `PROOF-NEEDS`, then `proof-debt`, so hypatia's
  CI-checked `verification/PROOF-STATUS.adoc` is the one shown. Other rows
  pick up this rule at the next full census.
* echidnabot's class is still the heuristic `theory`, from its file counts.
  Most of its proof files are prover fixtures (PROOF-POLICY §3); one
  theorem is real theory.
