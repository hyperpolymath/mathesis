= Cross-prover reconciliation (pointer)
:revdate: 2026-11-10

This file was the hand-written reconciliation register of Mathesis. On
2026-11-10 (re-anchoring plan WO 2.4) its parts moved to the places that own
them. The file stays at this path because other repositories cite it. The
last version of the register is in the history of this file.

== Where each part is now

The policy::
The canonical Agda invocation is PROOF-POLICY §2.1. The correspondence
evidence for Lean and Rocq, and the status vocabulary (`NOT-INVENTORIED` to
`QUARANTINED`), are PROOF-POLICY §2.2. Proof Witness Grades are PROOF-POLICY
§8. See
https://github.com/metadatastician/standards/blob/main/3-practice/PROOF-POLICY.adoc[metadatastician/standards `3-practice/PROOF-POLICY.adoc`].
A correspondence state is not a grade, and a grade is not a correspondence
state.

Grades::
Mathesis types no grade by hand. The claims registry derives each grade from
the home repository's receipt with the canon reader of PROOF-POLICY §8.5.1:
link:../atlas/generated/registry.adoc[`docs/atlas/generated/registry.adoc`],
from the pins in `docs/atlas/claims/claims.jsonl`. The Mathesis row of the old
register is now the claim `hyperpolymath/mathesis#THY-1` there.

Bridges::
A relation between artefacts in two repositories is a bridge record in
`docs/atlas/claims/bridges.jsonl`, with the generated view
link:../atlas/generated/bridges.adoc[`docs/atlas/generated/bridges.adoc`].
The two cross-repository rows of the old register are candidates there: the
squeakwell R3 and R9 merge laws (echo-types and verisimdb), and the MaxPlus
rows of choreographic-types (choreographic-types and tropical-types).

The other rows::
The other rows were to-do items inside one repository. Each home repository
owns its claims and records their status in its own status document. The
catalogue names that document for each repository
(link:../atlas/generated/catalogue.adoc[`docs/atlas/generated/catalogue.adoc`],
column "Proof-status doc"). On 2026-11-10 the canon reader accepted no
receipt from these repositories, so the registry pins none of their claims.
The homes are:

`hyperpolymath/absolute-zero`, `hyperpolymath/affinescript`,
`hyperpolymath/choreographic-types`, `hyperpolymath/echidna`,
`hyperpolymath/echo-types`, `hyperpolymath/epistemic-types`,
`hyperpolymath/invariant-path`, `hyperpolymath/januskey`,
`hyperpolymath/kategoria`, `hyperpolymath/nextgen-typing`,
`hyperpolymath/occupancy-types`, `hyperpolymath/proof-burrower`,
`hyperpolymath/residual-evidence-types`, `hyperpolymath/secret-types`,
`hyperpolymath/squeakwell` (rungs R5 to R8 and R10),
`hyperpolymath/trope-checker` and `hyperpolymath/vcl-ut`.
