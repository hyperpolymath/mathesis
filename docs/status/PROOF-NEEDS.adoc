APP-1 to APP-4 are about the cohort model of the applied shelf (re-anchoring
plan WO 4.2, owner rulings 2026-11-12). Each statement would be true of any
implementation of the model, so each is theory by PROOF-POLICY §1: proved in
Agda and re-checked in Rocq and Lean. The model is written over an abstract
number structure, so APP-2 and APP-3 need only its laws, not the laws of one
number type. They are not theory-shelf admissions: no estate rule depends on
them yet. Each worked example is already checked by Agda; a checked example is
not a proof of the property.

No Mathesis obligation concerns an ABI or an FFI: since WO 3.2 the deed
declares neither capability.

The template example proofs of the RSR template (Idris2, TLA+, and one
example each for Agda, Rocq and Lean) were removed in WO 4.1 of the
re-anchoring plan. They were never Mathesis obligations.

== Banned patterns

No proof file may contain an unproven escape: `postulate` (Agda),
`Admitted` (Rocq), `sorry` (Lean), `believe_me` or `assert_total`
(Idris2). For Agda, Rocq and Lean, `scripts/check-proofs.sh` enforces this
in CI: it compiles each gated module, then audits its axioms, and
`tests/proofs/gate_controls_test.sh` shows that a planted escape fails.
