APP-1 to APP-4 are about the cohort model of the applied shelf (re-anchoring
plan WO 4.2, owner rulings 2026-11-12). Each statement would be true of any
implementation of the model, so each is theory by PROOF-POLICY §1: proved in
Agda and re-checked in Rocq and Lean. They are not theory-shelf admissions:
no estate rule depends on them yet.

The Agda leg holds for the model as it runs. APP-1 and APP-4 hold for any
number structure: one statement carries both (`Covers`, in
`Applied/Status.agda`). APP-2 and APP-3 hold for any ordered abelian group
(`Laws`, in `Applied/Cash.agda`), and `Applied/IntLaws.agda` proves that
the integer instance of the worked examples is one. The Rocq and Lean legs
(`verification/proofs/coq/Cohort.v`, `verification/proofs/lean4/Cohort.lean`)
restate the same definitions and re-prove every theorem, the integer laws
included. Every module is gated: no postulate in an Agda import cone, every
Rocq theorem closed under the global context, and no axiom in any Lean
theorem. The receipt `verification/receipts/theory_praxis.deed` records the
three legs of each, and the canon reader derives `PWG-1` for each (2026-11-13).

No Mathesis obligation concerns an ABI or an FFI: since WO 3.2 the deed
declares neither capability.

The template example proofs of the RSR template (Idris2, TLA+, and one
example each for Agda, Rocq and Lean) were removed in WO 4.1 of the
re-anchoring plan. They were never Mathesis obligations.

== Banned patterns

No proof file may contain an unproven escape: `postulate` (Agda),
`Admitted` (Rocq), `sorry` (Lean), `believe_me` or `assert_total`
(Idris2). For Agda, Rocq and Lean, `scripts/check-proofs.sh` enforces this
in CI: it compiles each gated module, then audits its axioms, and
`tests/proofs/gate_controls_test.sh` shows that a planted escape fails.
