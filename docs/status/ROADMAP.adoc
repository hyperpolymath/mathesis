=== First theory theorem (2026-11-09)

* THY-1, `verification/proofs/agda/FeatureReachability.agda`: reachability
  in a dependency graph is monotone under additive features. It backs the
  `--all-features` rule in the standards upstream dependency watch.
  Re-proved in Rocq (`verification/proofs/coq/`) and Lean
  (`verification/proofs/lean4/`), both `RECONCILED`: `PWG-1` since 2026-11-10 (`PWG-2ii` before),
  recorded in `docs/status/PROOF-STATUS.adoc`. Transport was not possible because
  Lambdapi's Rocq and Lean exports drop rewrite rules.
* Proof lanes (2026-11-10, re-anchoring plan WO 1.4, ruling D-8 (a)): CI
  checks Agda, Rocq and Lean inside the pinned Guix shell
  (`build/channels.scm`, `build/manifest.scm`) on every commit, with no path
  filter, and asserts each version: Agda 2.7.0.1, Rocq 8.18.0, Lean 4.29.0.
  The THY-1 record names Agda 2.6.3 and Lean 4.15.0, so those two receipts
  are earned again at the new versions; Rocq stays at 8.18.0. The first
  green run on `main` (run 42896264290, commit `336768958d01`) earned them:
  each witness passed with an unchanged file digest and a clean axiom
  report, so the receipt derives `PWG-1`. The toolchain step takes 22 to 35
  minutes per run, because Guix builds some of its own modules at the pin.
* Three findings on the way. The Guix `agda` 2.7.0.1 package ships without
  the interfaces of its primitive modules in a read-only store, so the gate
  gives Agda a writable copy of its data directory (`Agda_datadir`); that
  defect belongs to Guix. The `agda-stdlib` 2.3 package of the pinned Guix
  does not build (it fails on the Guix build farm in every build since
  2026-10-18), so `Properties.agda` now uses `Agda.Builtin` only. At the old
  pin `ae77aeb` Guix had no substitute for itself, so the pin moved to
  `8edb9da` (owner rulings 2026-11-10).
* Gate gap closed (2026-11-10, re-anchoring plan WO 1.3):
  `scripts/check-proofs.sh` now audits each gated module after it compiles.
  Rocq: `Print Assumptions` for each declared theorem. Lean: every declared
  theorem must depend on no axiom. Agda: the postulate scan of januskey over
  the first-party import cone. `tests/proofs/gate_controls_test.sh` plants an
  `Admitted`, a `sorry` and a `postulate`; each fails the gate, and each fails
  to fail on the old gate. Under Lean 4.29.0 `simp` brought `propext` into
  `ApiTypes.lean`, which now proves both laws by `rfl`.
