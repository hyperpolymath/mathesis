= Mathesis Roadmap

== Current Status

Initial development phase.

=== Applied Systems (2026-11-07)

* Added the owner-requested `applied-systems/` area for reusable applications,
  beginning with accounting, finance, decision science and organisational design.
* Seeded an exploratory accountability-based management-accounting design,
  decision record, event map and shared evidence/type-assurance guidance.
* No private case data, executable model, empirical validation or formal proof
  is claimed by this documentation contribution.
* Next: define a minimal data schema and a synthetic worked implementation;
  allocate and record proof obligations when executable work begins.

=== First theory theorem (2026-11-09)

* THY-1, `verification/proofs/agda/FeatureReachability.agda`: reachability
  in a dependency graph is monotone under additive features. It backs the
  `--all-features` rule in the standards upstream dependency watch.
  Re-proved in Rocq (`verification/proofs/coq/`) and Lean
  (`verification/proofs/lean4/`), both `RECONCILED`: `PWG-2ii`, recorded
  in `docs/status/PROOF-STATUS.adoc`. Transport was not possible because
  Lambdapi's Rocq and Lean exports drop rewrite rules.
* Next: CI lanes for Rocq and Lean. Only the Agda gate runs in CI, so
  each witness has a current receipt only from a local run, and `PWG-1`
  needs one per commit.
* Gate gap: `scripts/check-proofs.sh` passes a Rocq file with `Admitted`
  and a Lean file with `sorry`, because it checks only the compiler's
  exit and error lines. Both compile, and the axiom reports name them.
  The Rocq and Lean gates should also fail when `Print Assumptions` or
  `#print axioms` lists an axiom for a gated theorem.
