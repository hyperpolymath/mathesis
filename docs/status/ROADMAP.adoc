= Mathesis Roadmap

== Current Status

Phase `incubating`, maturity `experimental` (the deed's `(status)` and
`(maturity)`). The re-anchoring plan
(`docs/proposals/mathesis-re-anchoring.adoc`) is at stage 3, "tell the
truth". The stages are under <<stages>>; the rulings that steer them are
under <<rulings>>.

What comes next is drawn as a tech tree, the ultraplan
(link:../ultraplan/generated/ultraplan.adoc[`docs/ultraplan/generated/ultraplan.adoc`],
from the data in `docs/ultraplan/`). Its frontier is the work that is ready, to
start when an active slot is free, and each advisor of the council, except the
private me advisor, names a pick from it. This roadmap keeps the record of what happened; the tree says what each
piece enables.

=== Transport blockers, not yet filed upstream (2026-11-17)

PROOF-POLICY §2 puts Dedukti transport first and a re-proof by hand second.
Two upstream defects block transport today, so the Lean and Rocq legs of
THY-1 and of echidnabot's T-RECEIPT are re-proofs. Owner ruling 2026-11-17:
record them here first and file them upstream later. Both were reproduced in
a clean container on 2026-11-09.

* *Agda2Dedukti* at `c7c7d671c658c278c0cd1a608268c71175adab7e` (its pinned
  Agda fork reports 2.6.3; built with stack 3.11.1 and GHC 8.10.7) stops with
  `__IMPOSSIBLE__` at `Agda/TypeChecking/Sort.hs:216` on a parameterised
  record in `Set₁`:
+
[source,agda]
----
{-# OPTIONS --safe --without-K --exact-split --no-sized-types --no-guardedness #-}
module T2 where
record W (C : Set) : Set₁ where
  constructor w
  field
    E : Set
    e : E
----
+
The same record without the parameter, a parameterised record in `Set`, and
a `data` type in `Set₁` all translate. The fork also rejects
`--cubical-compatible`, the flag PROOF-POLICY §2.1 requires, and joins
`--outDir` to the file name without a separator. A `data` restatement gets
past the crash and then fails on an erased argument.
* *Lambdapi* 4.0.0 (opam): `export -o raw_lean` and `-o raw_coq` drop every
  `rule` ("Command not translated") but still emit the definitions that
  type-check only by those rules. Lean 4.35.0 and Coq 8.18.0 then reject the
  output. Reproducer:
+
----
symbol O : TYPE;
symbol imp : O → O → O;
injective symbol Prf : O → TYPE;
rule Prf (imp $a $b) ↪ Prf $a → Prf $b;
symbol K (a b : O) : Prf (imp a (imp b a)) ≔ λ x _, x;
----
+
Side defects: a symbol named `Prop` is emitted as is and collides with the
keyword in both targets, and the Lean export writes Mathlib `set_option
linter.style.*` lines that core Lean rejects.

Next action: the owner files both reports (Deducteam/Agda2Dedukti and
Deducteam/lambdapi). The transport row of a theorem stays a re-proof until a
fixed release passes the round trip on that theorem.
