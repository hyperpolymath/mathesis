= Test needs of Mathesis

The tests of the Mathesis parts, what they show, and what is still missing.
The readiness grade that rests on them is in link:READINESS.adoc[READINESS].
Each result was observed on 2026-11-11, on `main` at `f778a19`, unless it
names a CI run.

`just check-views` runs the census, atlas and registry suites; CI runs
`just check` and both control tests in the pinned Guix shell
(`.github/workflows/agda-proof-policy.yml`). The other tests under `tests/`
(`workflows/`, `e2e/`, the proven suite) check the template scaffold, not a
Mathesis part.

== Needs

* *A dogfood log.* No dated record shows the census and the registry in use
  over an evidence window (needed for CRG C).
* *A live census test.* Every census test is offline. No test clones a real
  repository, so a change in the GitHub clone behaviour shows only in the
  next full census.
* *Applied shelf.* No test exists, because no executable component exists
  (WO 4.2).
* *Contract probes.* The six `must` probes have no runner; a test that runs
  them in CI would turn the contract into a gate.
