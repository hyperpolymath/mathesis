= Troubleshooting Mathesis

Known failures and their fixes. Each entry was met in practice; add one when
a failure takes real time to diagnose.

== `just` fails on `provision::build`

*Symptom*: `error: Expected '&&', comment, end of file, ... but found '::'`.

*Cause*: an old `just` that does not know module paths.

*Fix*: use the version that `mise.lock` pins (1.56.0), and check its
checksum against `mise.lock`.

== `validate-claude-md` or `validate-coapt` fails with `nickel: command not found`

*Fix*: install Nickel 1.18.0. CI checks the release binary against the
SHA-256 in `.github/workflows/dogfood-gate.yml`.

== `validate-coapt` reports `DRIFT`

*Cause*: a contractile or a deed clause changed, and the receipt was not
regenerated.

*Fix*: run `just coapt` and commit the receipt. Never edit the receipt by
hand.

== The registry stops with `set MATHESIS_STANDARDS`

*Fix*: point `MATHESIS_STANDARDS` at a `metadatastician/standards` checkout
whose reader file has the digest that `READER` in
`scripts/registry/claims-registry.mjs` names.

== The canon capability checker reports `no profile at .../rsr-profile.a2ml`

*Cause*: the copy of `check-rsr-profile.sh` at the CI pin of `standards`
still reads the retired `.a2ml` profile.

*Fix*: run the checker from `standards` main, which reads the deed's
`(rsr-profile)` clause. Without network access to the Actions API, omit the
`owner/repo` argument; the checker then skips its live step.

== `scripts/check-proofs.sh agda` fails on `--print-agda-data-dir`

*Cause*: Agda older than 2.7.0.1.

*Fix*: run the proof checks in the pinned Guix shell (see
link:contributing.adoc[contributing]).

== `just validate-repo-map` reports a stale map

*Cause*: a tracked path was added, moved or removed.

*Fix*: run `just repo-map` and commit `docs/architecture/REPOSITORY-MAP.adoc`.

== `just crg-grade` prints `X`

*Cause*: the template recipe reads `READINESS.md` at the root, which does
not exist. The grade is in `docs/status/READINESS.adoc`.
