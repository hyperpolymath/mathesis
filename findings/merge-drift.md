# Merge conflicts, drift, template propagation, agent clashes (empirical)

Corpus: 484 cloned repos, 93,345 commits (git log over all of them), HEAD trees via `git ls-tree` (271,170 blob entries). Scripts: /tmp/m1.sh, m2.sh, m3.sh, sweep.awk, base.awk (scratch; re-runnable). 48 repos failed to clone: no claims about them.
Caveats: blobless clones (history complete except six private repos at depth 50); `hyperpolymath/explore` (10,752 commits, 4,730 merges) is a vendored GitHub topic-repo history and inflates merge counts; subject-grep counts are lower bounds on real conflict handling (many conflicts are resolved in an unlabelled merge).
