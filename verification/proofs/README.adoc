= Formal verification proofs

The sources of the theorems whose home is Mathesis, one directory for each
prover. The admission rule and the theorem index are in
link:../../docs/theory/README.adoc[the theory shelf].

[cols="1,3",options="header"]
|===
|Path |Contents

|`agda/`
|The Agda source of truth (PROOF-POLICY §1)

|`coq/`
|The Rocq re-proofs

|`lean4/`
|The Lean re-proofs

|`<prover>/MANIFEST`
|The modules that the proof gate checks (`gated`)
|===

== Checking

`scripts/check-proofs.sh <prover>` compiles each gated module and then audits
its axioms. CI runs it in the pinned Guix shell through `just check-proofs`:

[source,bash]
----
guix time-machine -C build/channels.scm -- shell -m build/manifest.scm -- just check-proofs
----

The template example proofs (Idris2, TLA+ and one example each for Agda,
Rocq and Lean) were removed in WO 4.1 of the re-anchoring plan.
